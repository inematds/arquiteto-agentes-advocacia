# Agentes no Escritório de Advocacia · Caderno

Caderno de profissão (formato v5, 3 aulas) do curso [Arquiteto de Trabalho com IA](https://inematds.github.io/pffia/): um processo do escritório ou do jurídico interno especificado com agentes de IA, sigilo profissional como restrição, prazo sempre chamando humano e nada assinado nem protocolado por máquina. Usa o [Kit do Arquiteto de Agentes](https://inematds.github.io/kit-arquiteto-agentes/) com o preset de advocacia.

Publicado em https://inematds.github.io/arquiteto-agentes-advocacia/
